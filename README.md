# mintofit-site

MintoFit'in tanıtım sayfası ve yasal metinleri. GitHub Pages ile yayında:
https://mreness.github.io/mintofit-site/

- `gizlilik.html` — Gizlilik Politikası (App Store Connect'te gizlilik linki)
- `kosullar.html` — Kullanım Koşulları / EULA
- `destek.html` — Destek (App Store Connect'te destek linki)

Uygulama içindeki linkler `src/constants/links.ts` üzerinden bu adrese bakar.
